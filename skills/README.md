# Skills

Five skills vendored from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
(MIT, `LICENSE` in this folder), adopted as this project's craft baseline:

- **taste-skill/** — anti-slop frontend discipline: brief inference, dials, layout
  discipline, AI-tell bans, pre-flight check.
- **minimalist-skill/** — premium utilitarian minimalism: hairline structure,
  typographic hierarchy, pastel semantics.
- **redesign-skill/** — audit-first protocol for evolving existing surfaces.
- **image-to-code-skill/** — image-first pipeline: generate references, analyze,
  implement to match.
- **output-skill/** — full-output enforcement: no half-finished work, no placeholder
  comments.

Project-native image skills are progressively disclosed through
`../image-generation/README.md`; they do not live in this always-available craft-skill
directory. The 3D hardcover skill lives at `../book-asset/SKILL.md` (also linked from
`.agents/skills/book-asset/`).

Precedence when anything conflicts: `../DESIGN.md` > `../AGENTS.md` > these skills >
model defaults.
