# Adopted skills

Two skills vendored from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
(MIT license, `LICENSE` in this folder):

- **taste-skill/** (`design-taste-frontend` v2) — anti-slop frontend discipline:
  brief inference, the three dials, layout discipline, AI-tell bans, pre-flight check.
- **minimalist-skill/** (`minimalist-ui`) — premium utilitarian minimalism: warm
  monochrome + hairline structure, typographic hierarchy, pastel semantics.

Both are adopted as this project's craft baseline. Precedence when anything
conflicts: `../DESIGN.md` > `../AGENTS.md` > these skills > model defaults.
`AGENTS.md` §0 lists the few places DESIGN.md adjudicates or bounds them.
